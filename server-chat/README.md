# Server Chat

Servidor independiente para el chat en tiempo real de ProjectMarket.

## Comandos

```bash
npm install
npm start
```

Para desarrollo:

```bash
npm run dev
```

El servidor usa `PORT=3001` por defecto y se conecta a Postgres con `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME` y `DB_PASSWORD`, o con `DATABASE_URL`.
